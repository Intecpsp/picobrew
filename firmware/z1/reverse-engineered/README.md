# PicoBrew Z1: OEM reconstruction

The recovered Z119 Core/Head application, drivers, programs and original-image
comparison evidence are implemented under
[`z-series/reverse-engineered`](../../z-series/reverse-engineered/README.md).

The preserved Z images do not establish which physical Z1 revisions use
that application or its flash layout. This directory reserves the model-specific
location until the original device identity, wiring and layout are established.
The generic `z-series` build is not relabeled as a qualified Z1 image.
