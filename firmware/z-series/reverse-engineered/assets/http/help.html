Z Program Maker

Description

The Z Program Maker is small and simple web page that allows designing programs for the Z. It also provides the ability to directly push programs to the Z, so that you can execute right away the programs you designed. The Z Program Maker page is embedded into the Z firmware along with an HTTP server. To access it, you will need a device, such as a laptop or a mobile phone, connected on the same WiFi network as the Z, as well as a browser running on that device.

The Z Program Maker also allows you to export programs as JSON files, so that you can archive them as you wish. You can also import programs previously exported by simply drag and dropping JSON files onto the "IMPORT" button. Finally, you can also manually write JSON files and import them provided that they comform to the JSON Format described below.

How To Connect

  • On the Z, navigate to Settings > Network > WiFi Details
  • Take note of the IP Address (i.e. 192.168.0.123)
  • Grab a device (i.e mobile phone) on the same WiFi network as the Z
  • Open a browser and navigate to the IP address (ie http://192.168.0.123)

How To Use

It is dead simple:

  • Add steps as desired
  • Click "PUSH TO Z" to push the program to the Z
  • On the Z, just click "Start" when ready to proceed
Please note that the "SAMPLE" button loads a sample program that you can user to try things out or get an idea of how a program looks like.

JSON Format

Here is a sample JSON program. All quantities within JSON file are always expressed in metric units (temperatures are in Celsius degrees). Please find detailled description of each fields further down below. 


{
  "Name": "My Sample Recipe",
  "IsBeer": true,
  "UsePicoPakMode": false,
  "Steps": [
    {
      "Name": "Heat Water",
      "StepType": 1,
      "Location": 1
      "Temp": 67.1,
      "Time": 0,
      "Drain": 0,
    },
    {
      "Name": "Mash",
      "StepType": 1,
      "Location": 2
      "Temp": 67,
      "Time": 5400,
      "Drain": 480,
    },
    ...
  ]
}
Program properties:
  • Name: name of the program as it will appear in BrewHouse.
  • IsBeer: boolean indicating whether or not typical setup beer instruction should be shown on the Z.
  • UsePicoPakMode: whether or not to use PicoPak Adjunct compartments.
Steps properties:
  • Name: name of the step as it will appear in LogHouse.
  • StepType: number identifying the type of step:
    • 1: Active steps generating heat
    • 2: Pause
  • Location: number identifying the compartment where to direct the wort/liquid to:
    • 1: Passthrough (i.e. Keg)
    • 2: Mash Compartment
    • 3: Adjunct Compartment #1
    • 4: Adjunct Compartment #2
    • 5: Adjunct Compartment #3
    • 6: Adjunct Compartment #4
  • Temp: target temperature in Celsius.
  • Time: number of minutes to hold temperature for.
  • Drain: number of minutes to run the drain pump for at the end of the steps.
