# PicoBrew Zymatic

The standalone firmware runs PicoBrew’s original 1.1.14 brew controller. Version 1.2.0 provides local recipe selection, a configurable Hub address and wired monitoring. Version 1.3.0 adds dial pairing, remote operation of the displayed menu and stored brew measurements. First conversion uses 1.2.0. The USB installer can select 1.3.0 after verifying a compatible boot configuration on the same machine. Physical installation and a supervised brew are still pending.
